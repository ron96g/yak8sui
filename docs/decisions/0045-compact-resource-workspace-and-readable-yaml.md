# Tighten resource browsing and prioritize YAML readability

Keep the existing resource workspace structure while reducing avoidable whitespace. Lay out filters on a responsive grid, constrain stable table columns, reduce row padding, and retain an internal horizontal scroll boundary on narrow screens. Make each row the single inspect action, with an accessible name, pointer treatment, and Enter or Space keyboard activation; remove the redundant Actions column so the resource name has more useful width.

Treat YAML as the primary content of its detail tab. Add a compact manifest header with read-only or edit state, increase the editor's type size and line spacing, retain line numbers and folding, and allocate more vertical space to the editor. Keep long lines horizontally scrollable so they do not push later manifest sections out of the viewport. Keep mutation actions in the dialog footer and preserve the existing role-based visibility and backend enforcement.
